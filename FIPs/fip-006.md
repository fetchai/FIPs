## Abstract

The intent is to align values of the block limit parameters `max_gas` and `max_bytes` on the Mainnet with higher
values on Dorado testnet.<br/> 
Currently, the block limit values on Mainnet are **half** of what is on Dorado testnet.

## Motivation

The main goal is to ensure that the deployments made & tested on Dorado testnet can be freely deployed on the Mainnet
without limitations or necessity to do further changes.<br/>
The secondary goal is to enable more complex solutions, which require more gas to execute. 

## Specification

We are proposing to set block `max_gas` limit to 6'000'000 gas (from 3'000'000 gas) and the block `max_bytes`
limit to 600'000 bytes (from 300'000 bytes), which will align these values with Dorado testnet.

## Rationale

The block limits values on Dorado testnet have been raised to double of what they are on Mainnet for quite some time -
since 2022-09-08 (see the [gov proposal #6](https://hub.fetch.ai/dorado-1/proposals/6),
TX [91E286...E533B0](https://hub.fetch.ai/dorado-1/transactions/91E286261B58BA83D202A1D8308A8873EDA0215AC436D5921AE33A0B07E533B0)).

The higher values of block limits params will allow deployments of more complex solutions on the chain.<br/>
This applies especially for contract based solutions, where the size of contract binary code, and the ability to
execute more complex code (and so more gas consuming) have been main limiting factors.
